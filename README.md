# Curso Java Avançado - Softblue

Este repositório contém todos os exercícios, projetos práticos e códigos desenvolvidos por mim durante o curso **Java Avançado** da **Softblue**.

## 🚀 Tecnologias Utilizadas
* **Java** (Linguagem de programação principal)
* **Eclipse IDE** (Ambiente de desenvolvimento)
* **Git & GitHub** (Controle de versão e hospedagem do código)

## 📂 Estrutura do Repositório
### O projeto está organizado por duas pastas:
1. **Materiais**:

Cada subpasta é um módulo do curso, e em cada pasta dos módulos estão os slides das aulas e exercícios propostos sobre aquele conteúdo.

2. **Exercícios**:

Cada subpasta é um módulo do curso, os mesmos correspondentes da pasta "Materiais", sendo cada pasta um workspace da IDE Eclipse. Dentro de cada workspace tem os Exercícios, e cada um é um Java Project do Eclipse com a resolução concluída.

## 🛠️ Como rodar os projetos
1. Faça o clone deste repositório:
```bash
git clone git@github.com:joaolucas92/softblue-java-avancado.git
```
